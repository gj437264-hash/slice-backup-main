Key Features

Full & Partial Backups

Export database tables, plugins, themes, and uploads together or independently into lightweight, compressed archives.

Chunked Data Processing

Avoid server timeouts and memory exhaustion on shared hosts or strict edge proxies during large site migrations.

Database Serialization Clean

Automatically handles search-and-replace for domain URLs while preserving serialized PHP data arrays and structures intact.

How to Test & Contribute

  1. Download the compiled .zip package from the latest Releases tab.
  2. Upload and activate the zip file on a test or staging WordPress site (LocalWP, staging server, or dev sandbox).
  3. Run a test backup, export the site, and attempt an import/migration on a fresh WordPress setup.
  4. Report bugs, memory leaks, or execution failures under GitHub Issues.
